# Portafolio Frontend — Diseño de Sistemas en Internet

## Descripción
Página web personal desarrollada como taller práctico de la unidad de
"Diseño de sistemas en Internet", aplicando la estructura básica de HTML.

## Objetivo general
Identificar la estructura básica del frontend mediante HTML, organizando
correctamente los elementos de una página web.

## Contenidos aplicados
- Estructura básica del HTML
- Etiquetas principales: `<html>`, `<head>`, `<body>`, `<h1>`–`<h6>`, `<p>`, `<ul>`, `<li>`
- Creación de una página simple

## Estructura del proyecto
1.	Crear un archivo llamado index.html.
2.	Estructurar la página personal con:
- Un encabezado principal con su nombre.
- Un párrafo de presentación personal.
- Una lista de intereses o habilidades.
- Añadir una imagen y enlaces a redes o sitios favoritos.


## Cómo visualizarlo
1. Abre el archivo `index.html` en el repositorio.
2. Clic en el botón **Raw** o descarga el repositorio y ábrelo en el navegador.
